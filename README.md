# Social Media App

A modern, responsive social media application built with React, designed to provide a smooth and interactive social networking experience. Users can create posts, share images, interact with other users, manage their profiles, and communicate through comments and replies.

## Live Demo

🌐 **Live Website:** [Social Media App](https://social-media-space.vercel.app)

💻 **GitHub Repository:** [MohamedOsama1907/Social-App](https://github.com/MohamedOsama1907/Social-App)

## Features

### Authentication & User Management
- User registration and login.
- Protected routes for authenticated users.
- User profile management.
- Profile photo upload.
- Change password functionality.
- Session-based authentication using browser storage.

### Posts
- Create text posts, image posts, and posts containing both text and images.
- View posts in a dynamic social feed.
- Share posts.
- View individual posts and their details.
- Paginated post loading.
- Responsive post cards and interactive actions.

### Comments & Replies
- Create comments with text, images, or both.
- Reply to existing comments.
- View comments and nested replies.
- Expand comments and replies using Show More functionality.
- Edit existing comments inline.
- Image previews and removal while creating or editing content.

### Social Interactions
- Like and unlike posts.
- Follow and unfollow users.
- Discover suggested users to follow.
- Visit other users' profiles.
- View profile information and posts.

### User Interface & Experience
- Modern, minimal, and professional design.
- Fully responsive layout for mobile, tablet, and desktop.
- Reusable React components.
- Interactive dropdown menus and form controls.
- Form validation and user-friendly notifications.
- Loading indicators and error handling.
- Consistent styling with Tailwind CSS.

## Technologies Used

- **React** — Building reusable and interactive UI components.
- **Vite** — Development environment and build tooling.
- **React Router** — Client-side navigation and routing.
- **Tailwind CSS** — Responsive styling and UI design.
- **Axios** — HTTP requests and API integration.
- **Formik** — Form state management and submission handling.
- **Yup** — Form validation.
- **Lucide React** — Icons.
- **Sonner** — Toast notifications.
- **Context API** — Managing shared authentication and user state.
- **REST API** — Backend communication and data management.
- **Vercel** — Deployment and hosting.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js installed.
- npm installed.
- Access to the backend API.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/MohamedOsama1907/Social-App.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Social-App
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.

## Project Structure

The application is organized into reusable components, pages, context providers, and supporting modules to keep the code maintainable and organized.

- **Components** — Reusable UI elements, forms, posts, comments, and replies.
- **Pages** — Application pages such as Home, Profile, Settings, and Post Details.
- **Context** — Shared authentication and user information.
- **API Integration** — Requests for posts, comments, profiles, and social interactions.
- **Routing** — Public and protected navigation.
